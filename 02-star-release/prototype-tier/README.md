# 星球发行 Tier 产品化 Demo

> Vercel Project: `star-release-tier`
> Source Root: `02-star-release/prototype-tier`
> Product: 星球发行（Managed Distribution）

## Demo 目标

把 Basic / Professional / Plus 从商业模型文档变成真实产品体验，验证：

- 当前合作等级如何被用户感知；
- Quota 如何进入曲库与发行流程；
- SLA 如何影响服务入口与响应方式；
- Plus 如何体现邀请 / 评审制 Partnership；
- 扩容如何成为独立付费能力；
- Tier 与现行合同分成保持解耦。

## 当前第一阶段

当前 `index.html` 为「我的合作方案」基线 Demo，并内置 Basic / Professional / Plus 三种账户状态切换。

已覆盖：

- 当前合作等级；
- 资源额度与使用量；
- 当前方案权益；
- 服务等级 / SLA；
- 合作评估；
- 三档方案对比；
- 曲库 / 年度发行扩容；
- Plus 评审制说明。

## 后续推进顺序

1. 全局 Shell 与 Tier 身份常驻；
2. 首页增加合作状态与额度摘要；
3. 专辑 / Track 创建接入 Quota；
4. 发行提交增加额度预占、临界提醒和超额阻断；
5. Basic 过渡期 / 超额治理；
6. Professional 优先服务；
7. Plus 专属运营与特殊项目；
8. Service Case；
9. 扩容申请 / 订单闭环；
10. 最后反向改造星球发行官网的三档合作叙事。

## 产品原则

- Tier 管合作深度；
- Quota 管资源成本；
- SLA 管人工服务成本；
- 分成政策独立于 Tier；
- Professional 不是付费会员；
- Plus 不公开售卖，采用邀请 / 评审制；
- 历史 DSP 在线内容与平台托管容量分开治理。
