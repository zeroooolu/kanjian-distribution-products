# 星球发行·企业版官网原型 v1.2

> 日期：2026-09-10  
> 状态：官网初稿 / 可视化产品讨论稿

## 目的

基于：

- `03-enterprise/product-definition-and-architecture-v0.1.md`
- `06-research/enterprise-white-label-api-competitor-research-2026.md`
- 企业版方向草稿
- 星球发行与 AI 音乐发行现有品牌视觉

建立企业版官网原型，用于继续讨论产品定位、接入方式、功能架构、商业模式与对外表达。

## v1.2 调整

- 官网主导航收敛为：`产品 / 定价 / API`；
- 移除 `STAR DISTRIBUTION · ENTERPRISE`、`适用业务`、`发行引擎`、`接入方式` 等装饰性小标签；
- `White-label` 对外统一改为 `品牌发行平台`；
- 发行引擎、接入方案、品牌配置示意全面中文化；
- API、Webhook、DDEX、DSP 等必要技术缩写保留；
- 企业级接入中的英文能力标签改为中文能力列表；
- 新增官网定价区块，先采用 `基础服务 + 使用规模 + 可选能力` 的计费表达，不写死未确认金额；
- Hero、产品方案与控制台示意进一步减少营销性英文和辅助标签。

## 当前页面结构

1. Hero：让企业拥有专属音乐发行平台
2. 产品方案
   - 品牌发行平台
   - 发行 API
   - 企业级深度接入
3. 完整发行链路
4. 核心能力
5. 品牌与业务配置
6. 发行网络：中国与全球 DSP
7. 目标业务类型
8. 定价
9. 商务 CTA

## 视觉原则

- 延续星球发行产品家族蓝色主色；
- 复用 `/assets/star-logo.png`；
- 复用 `music-promotion` 仓库中的 DSP 彩色 Logo；
- 面向国内企业客户，以中文业务表达为主；
- B2B / Infrastructure 气质高于普通音乐人产品；
- 以产品控制台、API、发行链路与品牌配置界面作为主要视觉；
- 信息层级优先于装饰，减少无意义卡片化与营销性标签；
- 当前为纯 HTML + CSS 原型，便于快速迭代。
