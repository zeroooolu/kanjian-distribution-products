# 星球发行·企业版官网原型 v2.1

> 日期：2026-09-10  
> 状态：Enterprise Commercial Website / Product Demo
> 部署触发：2026-09-10 retry

## 当前目标

企业版官网用于把已经存在的发行系统能力产品化为一条完整的企业商业入口，而不是重新设计 Tenant、企业后台、下游 CP 门户、发行、DSP、报表、分账和提现等已有业务系统。

当前对外核心产品只有两个：

1. **品牌发行平台**：以企业品牌、独立域名、企业后台和客户发行门户开展完整音乐发行业务；
2. **发行 API**：把内容、发行、渠道、数据与收益能力接入已有网站、App 或内部系统。

DDEX / XML / Excel / SFTP 属于企业技术接入与交付方式，不作为第三种平级产品。

## v2.1 重构原则

本轮对 v2.0 做了整体复盘与重构，重点解决此前“产品文档卡片化、文字过小、重复表达、技术感过强、缺少视觉主次”的问题。

### 页面表达

官网围绕以下五个购买者能快速理解的信息展开：

- 快速建立企业品牌下的音乐发行服务；
- 连接中国及全球主流音乐平台；
- 从内容管理、发行到数据与收益，在一套平台中完成；
- 已有产品可以通过发行 API 接入；
- 看见音乐负责发行审核、平台交付和后续发行服务。

### UI / 视觉

- 减少重复卡片与大量小字号标签；
- 增大正文、标题与关键产品界面的视觉占比；
- 首页以一张较完整的企业发行工作台作为核心产品视觉；
- 品牌发行平台采用深色整屏产品展示，强化“完整产品”而非“功能模块”的感受；
- DSP 改为横向动态发行网络展示；
- API 使用品牌蓝整屏区块，与完整平台形成清晰的两种产品形态；
- 定价从套餐卡片改为更简洁的合作方式列表；
- 增加轻量滚动 Reveal、DSP marquee、API 能力切换与导航状态反馈。

### 首页结构

```text
Hero + 企业平台主视觉
↓
看见音乐业务规模证明
↓
品牌发行平台 / 发行 API
↓
从内容提交到音乐上线
↓
品牌发行平台完整展示
↓
全球发行网络
↓
发行 API
↓
```

首页不再重复展示“管理内容 / 发行音乐 / 查看数据 / 管理收益”等多组能力卡片；这些内容下沉至产品页。

## 竞品参考

当前官网结构重点参考：

- AudioSalad：短文案、强产品价值、服务模块不过度解释；
- FUGA：发行平台是核心业务工具，品牌发行与 API 作为企业扩展；
- SonoSuite：直接强调在企业品牌和域名下运营完整发行服务；
- LabelGrid：平台与 API 两种进入方式、公开 Developer Product、定价与产品关系清晰；
- Revelator：API 围绕数字发行、数据、版税与支付等业务结果组织。

最初 `star-distribution-enterprise.reylen55.chatgpt.site` 草稿中的“双商业模式”继续作为产品形态基线，但不沿用原草稿的临时视觉与未经确认的定价数字。

## 企业申请

申请页保持较轻的销售线索表单，只收集：

- 企业名称；
- 官网 / 产品地址；
- 联系人；
- 企业邮箱 / 手机；
- 企业类型；
- 期望产品；
- 曲库规模；
- 月发行量；
- 业务说明。

DDEX / XML / SFTP / Excel 等技术选择不放在首轮销售申请表，由后续方案确认阶段收集。
