接入星球发行企业 API

企业开放接口基于现有星球发行能力进行产品化封装。当前页面用于搭建开发者信息架构，正式 Endpoint 以接口映射结果为准。

接口路径与事件名为 Demo 示例，不代表最终生产定义。

1. 鉴权

API 凭证与 Enterprise Account、Tenant、套餐权限和使用配额绑定。

Authorization: Bearer <access_token>
Content-Type: application/json

2. 内容能力

现有能力覆盖艺人、专辑、歌曲、厂牌、文件、ISRC / UPC 等内容对象。

3. 发行能力

现有发行接口覆盖模板、发行预览、发行设置概况、发行列表等能力。

POST /v1/releases        # 示例：创建发行
GET  /v1/releases/{id}   # 示例：查询状态

4. 基础数据

统一提供国家地区、语种、角色、风格与 DSP 等发行基础数据。

5. Webhook

用于接收审核、交付、上线和失败等异步状态；正式事件模型在 API v1 阶段收口。

6. 日志与错误码

提供请求记录、响应状态、错误详情与 Webhook 投递结果。

7. 用量与配额

展示企业当前套餐、发行传输用量、额度和周期信息。
