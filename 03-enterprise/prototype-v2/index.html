HOW TO CHOOSE

品牌平台还是 API？看这三个问题。

你是否已有成熟前端？

没有 → 优先品牌发行平台；已有 → 可以优先 API。

你是否直接服务下游客户？

需要客户门户 → 品牌发行平台更快；只做内部系统 → API 更轻。

你是否需要复杂技术集成？

标准流程 → 在线平台即可；大型数据流 → API / DDEX / XML / SFTP。

FAQ

关于定价的常见问题。

年度平台费和发行使用费是什么关系？

年度平台费对应企业平台及版本能力；发行使用费按照实际“歌曲 × 目标渠道”产生的发行使用量计算。

基础版和专业版可以额外购买 API 吗？

可以。基础版与专业版可根据项目需要增购 API；企业版标准方案已包含 API 能力。

超过曲库规模怎么办？

可以升级版本或按扩容范围确认新的商业方案，大规模历史曲库迁移也可单独评估。

企业版为什么写“起”？

大型曲库、复杂迁移、DDEX、定制数据流和专属服务会根据项目实施范围确认最终报价。

发行流程

典型接入流程是先建立内容，再校验资料、提交发行并持续读取渠道状态。

// 接口结构示意，非正式生产 API
1. Create / sync artist, album and track
2. Validate release metadata
3. Configure target DSPs and schedule
4. Submit distribution
5. Receive status by query or webhook
6. Read reports / revenue after release

为什么先校验再提交？

发行链路包含大量渠道规则和必要元数据。把校验作为明确步骤，可以减少提交后才发现资料问题的返工成本。

Webhook

对于发行状态、交付结果等异步事件，Webhook 比持续轮询更适合企业级系统。

// 事件结构示意
{
  "event": "distribution.status.updated",
  "resource_id": "release_xxx",
  "status": "delivered",
  "channel": "example_dsp",
  "occurred_at": "..."
}

正式事件名称和字段以生产文档为准。

用量与额度

企业登录后可查看 API 调用量、发行使用量、套餐额度与超额情况。发行计费核心 Meter 为“歌曲 × 实际目标渠道”。

技术支持

开发文档解决“怎么接”，企业技术支持解决“为什么这次没接通”。专业版与企业版将按不同服务等级提供优先处理、专属技术支持或 SLA。
