# 星球发行·企业版 Prototype v3

本版本在 v2 的信息架构和视觉框架基础上，完成企业官网文案统一优化。

## 文案原则

- 去除第一、第二人称及指向性表达，包括“你 / 我 / 我们 / 你们 / 自己 / 自己的 / YOUR”等。
- 采用企业官网正式表达，减少口语化销售话术和反问句。
- 标题优先直接表达结论；正文直接说明功能、适用场景、接入方式和业务结果。
- 保持通俗易懂，避免过度包装和复杂行业术语堆叠。
- 不新增超出现有企业版产品范围的功能承诺。
