## API CAPABILITIES

# 按业务需要，接入对应能力。

围绕音乐发行全生命周期开放标准化能力。企业可根据现有产品架构选择所需模块，并通过统一接口完成业务集成。

### 01 · BUSINESS｜客户与基础资料

同步企业、合作客户、地区、语言、角色及发行所需基础配置，使发行能力与现有业务体系保持一致。

### 02 · CATALOG｜内容与曲库

创建和维护艺人、厂牌、专辑、歌曲、音频文件、封面及发行元数据，建立统一的音乐内容对象。

### 03 · DISTRIBUTION｜发行管理

创建发行任务，配置目标平台与发行时间，并支持发行后的修改、更新与下架等持续管理。

### 04 · STATUS｜渠道状态

获取审核、处理中、已上线、失败及异常状态，并将渠道处理结果同步回现有产品或业务系统。

### 05 · REPORTING｜数据与报表

获取发行后的平台数据与业务报表，为产品展示、运营分析及企业内部数据处理提供基础。

### 06 · SETTLEMENT｜收入与结算

获取收入报表、分账结果与结算状态，将发行后的财务数据接入企业现有业务与财务流程。

## END-TO-END FLOW

# 一套接口贯穿完整发行链路

从内容同步、资料校验到渠道提交、状态回传与后续数据，围绕统一业务对象连接发行全生命周期。

1. **同步内容与主体**：同步客户、艺人、厂牌、专辑、歌曲及相关文件与发行资料。
2. **完成发行校验**：校验元数据、文件及目标平台所需信息，确保发行资料满足提交要求。
3. **创建并提交发行**：配置目标平台、发行时间及相关设置，创建并提交正式发行任务。
4. **接收渠道状态**：通过查询或 Webhook 获取审核、处理、上线与异常状态，并同步至原有产品。
5. **获取数据与结算结果**：在发行完成后持续获取业务数据、收入报表、分账及结算状态。

## INTEGRATION OPTIONS

# 兼容实时 API 与批量数据交换

根据业务实时性、数据规模及既有技术体系，可选择 API、Excel、SFTP、XML 或 DDEX，支持从标准批量导入到行业级数据交换。

- **API**｜实时业务集成：适用于网站、App、SaaS 与内部系统的实时业务调用。
- **Excel**｜标准批量导入：适用于标准模板下的内容、元数据与发行信息批量处理。
- **SFTP**｜大规模文件交换：适用于大批量文件、音频素材及配套数据的稳定传输。
- **XML**｜结构化数据交换：适用于企业已有结构化数据流与批量业务系统对接。
- **DDEX**｜行业标准接入：适用于采用音乐行业标准协议的大规模专业发行数据交换。
