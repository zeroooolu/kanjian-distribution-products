FAQ

价格说明。

为什么除了年费，还有发行使用费？

年费对应企业系统、版本能力和服务；发行使用费按照实际发行量计算，一首歌曲发行到一个目标平台计一次使用量。

基础版和专业版能不能使用 API？

可以根据项目需要增购 API；企业版标准方案已包含发行 API。

曲库超过当前版本怎么办？

可以升级版本；大型曲库、复杂历史数据和迁移项目按实际范围确认方案。

企业版为什么是“¥129,800 / 年起”？

企业版通常会涉及更大的曲库、复杂系统对接、高级数据方式和专属服务，因此最终价格需要根据项目范围确认。

发行流程

典型流程包括建立内容、检查资料、提交发行、获取平台状态和后续报表。

// 接口结构示意，非正式生产 API
1. Create / sync artist, album and track
2. Validate release metadata
3. Configure target platforms and schedule
4. Submit distribution
5. Receive status by query or webhook
6. Read reports / revenue after release

Webhook

发行状态、平台处理结果等异步事件可通过 Webhook 回传。

// 事件结构示意
{
  "event": "distribution.status.updated",
  "resource_id": "release_xxx",
  "status": "delivered",
  "channel": "example_platform",
  "occurred_at": "..."
}

正式事件名称和字段以生产文档为准。
